## 3つのモード

<CardGrid>
  <Card title="Design Loop" icon="pencil">
    フロントエンドHTML生成 → スクリーンショット評価 → フィードバック。ピボット戦略で停滞を突破。
  </Card>
  <Card title="Fullstack Loop" icon="rocket">
    Planner → Sprint契約交渉 → Generator → QA Evaluator。スプリント単位で段階的に構築。
  </Card>
  <Card title="Continuous Loop" icon="star">
    V2 スプリントレス一括ビルド。Opus 4.6 のコンテキスト安定性を活用。
  </Card>
  <Card title="CLI (adl)" icon="terminal">
    統合CLI。`adl design "プロンプト"` で即実行。モデル・閾値・イテレーション数を柔軟に指定。
  </Card>
