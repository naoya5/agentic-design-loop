## 概要

Generator が HTML/CSS/JS を生成し、Evaluator が Chrome DevTools MCP でスクリーンショットを撮って視覚的に4基準で採点する。全イテレーションを実行し、ベストスコアの成果物を最終結果として `output/best/` に保存する。

## フロー

```
User Prompt → [Loop N times]
  → Generator（HTML生成）
  → Evaluator（スクリーンショット → 4基準採点）
  → スコア記録 & ベスト更新
  → 停滞検出 → ピボット指示（該当時）
→ ベストを best/ にコピー
```

## 評価基準

| 基準 | 重視度 | 内容 |
|------|--------|------|
| デザインの質 | **高** | 色・タイポグラフィ・レイアウトの統一感 |
| 独創性 | **高** | テンプレートではないカスタム設計 |
| 技術面 | 中 | タイポグラフィ階層、スペーシング、コントラスト |
| 機能性(UX) | 中 | 推測なしにタスクを完了できるか |

## ピボット戦略

直近3回のスコアが ±0.5 以内で停滞すると、Generator に「全く異なる美的方向性で再設計せよ」というピボット指示が発動する。

```
Iter 1: 6.5  ダーク×ゴールド
Iter 2: 6.8  微改善
Iter 3: 6.5  停滞
Iter 4: 7.3  🔄 ピボット → クリーム×クリムゾンに転換
Iter 5: 8.0  飛躍
```

## オプション

```bash
adl design "プロンプト" \
  --iterations 10 \
  --threshold 7.0 \
  --model claude-sonnet-4-6 \
  --early-exit  # 合格で即終了（デフォルトは全回実行）
```
